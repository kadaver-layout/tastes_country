## QA-04 — слой Битрикс: не выполняется (решение заказчика)

Контракты `submitDiscount` / `setCity` / `loadWeek` остаются точками интеграции (`window.TastesIntegrations`, комментарий в шапке `app.js`); demo-данные в `data.json` — fixture. PHP-шаблоны, инфоблоки и AJAX-контракт с sessid вне текущего объёма.

## QA-05 — недельная навигация: закрыто (локально)

Данные трёх недель лежат в `schedule.weeks` и отдаются в страницу скриптом `#schedule-weeks`; `renderWeek()` атомарно перерисовывает период, даты, строки с барами, маркер «сегодня» и disabled-состояния стрелок; pending блокирует обе кнопки (`disabled` + `aria-busy`), при ошибке DOM сохраняется. При наличии `TastesIntegrations.loadWeek` приоритет у серверного ответа, локальные недели — fallback. Границы: prev disabled на первой неделе, next — на последней.

## QA-06 — клоны и API рельсов: закрыто

Клоны первого/последнего слайдов помечены `data-rail-clone`, `aria-hidden`, полностью инертны (`inert`, удалены дубли `id`, снят `data-reel-toggle`); обработчики стрелок привязываются один раз (`data-rail-bound`), таб не попадает в клоны. Добавлен публичный идемпотентный API `window.TastesRails.init(root)` / `refresh(root)`: refresh удаляет только служебные клоны и пересоздаёт их, количество стрелок и обработчиков не удваивается.

## QA-07 — сценарий заявки: закрыто в рамках статики

`action="#"` убран; успех обрабатывает оба варианта ответа (`redirectUrl` → переход, `successMessage` → озвучиваемое подтверждение в форме); форма очищается только после подтверждённого успеха; при ошибке введённые значения сохраняются, сводка получает фокус и озвучивается (`role="alert"`), submit показывает pending и защищён от повторной отправки. Реальный endpoint — точка интеграции Битрикс (см. QA-04).

## QA-08 — 320 px: закрыто компромиссом

320 px ниже минимальной композиции макета (375). Добавлены переносы длинных заголовков и fallback `overflow-x: auto` на body для <360 px: контент полностью доступен прокруткой, ничего не обрезается `clip`-ом. Проектный минимум зафиксирован: 360 px без прокрутки, 320 px — доступность через скролл.
